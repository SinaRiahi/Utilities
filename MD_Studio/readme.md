# Markdown → PDF Converter

A modern browser-based Markdown editor with live preview and professional document export.

![Screenshot](screenshots/editor.png)

## ✨ Features

- 📝 Live Markdown editor
- 👀 Real-time preview
- 🔄 Bi-directional double-click sync (navigate seamlessly between editor and preview)
- 📄 Export to PDF
- 🌐 Export to HTML
- 📄 Export to DOCX
- 📐 KaTeX math rendering
- 📊 Mermaid diagrams
- 🎨 Light & Dark themes
- 🔍 Search & Replace
- 📑 Automatic Table of Contents
- 💻 Syntax highlighting
- 📱 Responsive design

## 🚀 Try it!

Open `[This page](https://sinariahi.github.io/Utilities/)` and select MD Studio.

No installation required. 
No connections required afterwards.

## 📦 Installation

well... some installation is required... If you want...
Clone the repository

```bash
git clone https://github.com/SinaRiahi/Utilities.git
```

Navigate to the project

```bash
cd Utilities/MDtoPDF
```

Open

```text
index.html
```

in your browser.
