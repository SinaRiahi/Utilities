# Utilities — File Transfer

A private, direct PC ↔ Mobile file transfer utility that works both directly in the browser on GitHub Pages (via WebRTC Peer-to-Peer) and over local networks.

## Features

- **GitHub Pages Ready (Zero Backend)**: Works 100% in the browser using WebRTC DataChannels and QR code pairing.
- **Direct Peer-to-Peer (P2P)**: Files are streamed directly between devices without going through any cloud storage.
- **End-to-End Privacy**: Nothing is stored on third-party servers.
- **4-Digit Quick Code Pairing**: Connect PC-to-PC or browser-to-browser easily by simply typing a 4-digit code.
- **QR Code Pairing**: Scan the QR code with iOS/Android camera to connect instantly.
- **Drag & Drop**: Select or drag multiple files of any type.
- **Real-time Progress & Download**: View upload/download progress and download files with one click.
- **Instant Auto-Sync Signals**: Automatic cross-device refresh triggers whenever an upload is completed.
- **Manual Refresh Button**: One-click refresh button with real-time feedback to quickly check for newly uploaded contents.
- **Light & Dark Theme**: Full theme support.

## How to use on GitHub Pages

1. Open `https://<username>.github.io/Utilities/File_transfer/` on your computer.
2. A QR code and pairing link are automatically generated.
3. Scan the QR code with your phone camera or open the link on another device.
4. Once connected (`🟢 Connected`), drag and drop files on either device to transfer immediately!
