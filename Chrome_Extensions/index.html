📖 Installation Guide (How to use in Chrome)

  1. Click the Download (.ZIP) button for the extension you want.
  2. Extract (unzip) the downloaded folder to a location on your computer.
  3. Open Google Chrome and navigate to chrome://extensions/ in your address bar.
  4. Enable Developer mode using the toggle switch in the top right corner.
  5. Click the Load unpacked button that appears in the top left.
  6. Select the extracted folder from step 2. The extension is now installed and ready to use!
