# Markdown → PDF Converter

A modern browser-based Markdown editor with live preview and professional document export.

## Features

- Live Markdown preview
- Export to PDF
- Export to HTML
- Export to DOCX
- Syntax highlighting
- KaTeX math support
- Mermaid diagrams
- Search & Replace
- Table of Contents generation
- Dark & Light themes
- Responsive layout

## Use Cases

This project is designed for quickly turning AI responses into:

- Study notes
- Documentation
- Reports
- Books
- Printable PDFs
