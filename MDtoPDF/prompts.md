**Comprehensive Notes**
Create comprehensive notes about [TOPIC].

The output is intended to be exported directly into a professional PDF document.
Formatting requirements:
- Use GitHub Flavored Markdown.
- Use exactly one H1 (#) for the document title.
- Use H2 (##) for major chapters.
- Use H3 (###) only when necessary.
- Never skip heading levels.
- Do not overuse headings.
- Insert
---pagebreak---
before every H2 chapter and wherever needed.
Content requirements:
- Explain concepts clearly.
- Include intuition before formal definitions.
- Include examples.
- Include diagrams using Mermaid whenever appropriate.
- Include tables whenever they improve readability.
- Use bullet lists where appropriate.
- Wrap every code example in fenced code blocks.
- Always specify the programming language.
- Render mathematical expressions using KaTeX.
At the end include:
## Summary
## Key Takeaways
## Common Mistakes
The output should be publication-quality and should require no manual formatting.
