# FileForge 📁

A lightweight, browser-based file management and batch renaming tool.

FileForge allows you to quickly modify file names without changing file contents. It is designed for bulk file organization tasks such as normalizing naming conventions, changing extensions, and preparing files for projects.

## ✨ Features

### 🔤 Case Conversion
- Convert file names to:
  - lowercase
  - UPPERCASE
- Independently control:
  - File name
  - File extension

Example:

```

MyPhoto.JPG

```

can become:

```

myphoto.jpg

```

or:

```

MYPHOTO.JPG

```

---

### 🧩 Extension Replacement

Change extensions without modifying the actual file data.

Example:

```

image.jpg

```

→

```

image.jpeg

```

Useful when you need naming consistency between formats that share the same file structure.

---

### ✏️ Rename Tools

Additional batch rename utilities:

- Add prefixes
- Add suffixes
- Find and replace text in filenames

Example:

```

photo_001.jpg

```

with prefix:

```

backup_

```

becomes:

```

backup_photo_001.jpg

```

---

## 📂 File Management

- Add individual files
- Add entire folders
- Drag and drop files
- Process multiple files at once
- Remove individual files from the queue
- Download files separately
- Export processed files as a ZIP archive

---

## 🔒 Privacy

FileForge runs entirely inside your browser.

- No files are uploaded to a server
- No external processing
- Your files stay on your device

---



## 🚀 Usage

1. Open FileForge in your browser
2. Add files or a folder
3. Choose your rename options
4. Click **Apply Changes**
5. Download the processed files
